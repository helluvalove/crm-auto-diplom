Резервное копирование базы данных
Выберите один из вариантов резервного копирования. Рекомендуется выполнять бэкап регулярно для сохранения данных.
Быстрый бэкап
Только структура БД

Создает файл с SQL-запросами для восстановления структуры базы данных (таблицы, индексы, связи). Не включает данные клиентов и заказов.

Полный бэкап
Структура + все данные

Создает полный дамп базы данных со всеми таблицами, данными клиентов, заказов, автомобилей и механиков. Рекомендуется для регулярных бэкапов.

Выборочный бэкап
Выбор таблиц для сохранения

Позволяет выбрать конкретные таблицы для резервного копирования. Полезно для частичного сохранения или миграции данных.
