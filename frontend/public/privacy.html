1. Цели обработки персональных данных

  • Формирование и отправка электронных PDF-счетов.
  • Ведение базы клиентов, истории обращений и автомобилей.
  • Уведомления о специальных предложениях.

2. Перечень обрабатываемых персональных данных

  • Идентификатор пользователя ВКонтакте (VK ID).
  • Фамилия, имя, отчество (при предоставлении).
  • Номер мобильного телефона.
  • Сведения об автомобилях: марка, модель, VIN‑номер, государственный регистрационный знак, год выпуска, пробег.
  • Информация о заказ‑нарядах: перечень услуг, стоимость, статус выполнения, фотографии (при отправке автомехаником).

3. Перечень действий с персональными данными

Оператор осуществляет сбор, запись, систематизацию, накопление, хранение, уточнение (обновление, изменение), использование, передачу (только в объёме, необходимом для исполнения договора оказания услуг), обезличивание, блокирование, удаление и уничтожение персональных данных.

Обработка ведётся как с использованием средств автоматизации (в информационной системе CRM), так и без них (в бумажных журналах, если применимо).

6. Отзыв согласия через профиль чат‑бота ВКонтакте

Пользователь имеет возможность отозвать своё согласие на обработку персональных данных непосредственно через интерфейс чат‑бота ВКонтакте. Для этого необходимо в главном меню бота нажать кнопку «Профиль», затем – «Отозвать согласие», и подтвердить действие, введя номер телефона, привязанный к профилю в системе.

Что происходит после отзыва согласия:

  • Все персональные данные пользователя (профиль, автомобили, заявки, история заказ‑нарядов) безвозвратно удаляются из информационной системы Оператора в момент подтверждения отзыва.
  • Чат‑бот блокирует возможность выполнения любых операций (запись, просмотр заявок, управление автомобилями) и возвращается в начальное состояние, в котором требуется повторное принятие согласия для возобновления работы.
  • При повторном обращении пользователь заново проходит процедуру регистрации: вводит ФИО, номер телефона и заново принимает условия Политики обработки персональных данных.
  • В случае, если отзыв согласия произошёл при наличии активного заказ‑наряда, такой заказ‑наряд автоматически аннулируется (переводится в статус «Отменён»), поскольку для его исполнения требуется обработка персональных данных пользователя.

Для дополнительной защиты прав субъектов персональных данных запись об отзыве согласия сохраняется в журнале событий Оператора в обезличенном виде (без привязки к конкретному субъекту) в течение одного года.
